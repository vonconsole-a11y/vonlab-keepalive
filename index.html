Supabase projelerin uyanık kalsın

Henüz proje yok

Sağ üstteki + kartına tıkla, Supabase proje ID'n ve API anahtarını gir, sayaç başlasın.

Veriler yalnızca bu tarayıcıda, cihazında saklanır. API anahtarların hiçbir yere gönderilmez — yalnızca kendi Supabase projene istek atmak için kullanılır.

Yeni proje ekle

Proje ID ve API anahtarı sadece bu cihazda saklanır.

Proje ayarları → General → Reference ID. (xyz.supabase.co içindeki "xyz" kısmı)
Aşağıdaki SQL'i Supabase → SQL Editor'da çalıştırıp tabloyu bir kere oluştur.
create table if not exists public.keepalive ( id bigint generated by default as identity primary key, created_at timestamptz not null default now() ); alter table public.keepalive enable row level security; create policy "keepalive allow all" on public.keepalive for all using (true) with check (true);

Henüz proje yok

Sağ üstteki + kartına tıkla, izlemek istediğin Supabase proje ID'n ve API anahtarını gir. Bu uygulamanın verileri de kendi Supabase projende saklanır — sağ üstteki SQL butonundan tabloyu oluşturman gerekiyor.

Bu panelin verileri (proje listeni) kendi Supabase projende tracked_apps tablosunda saklanır — tarayıcıda hiçbir şey tutulmaz.

Yeni proje ekle

İzlenecek Supabase projenin bilgilerini gir.

Proje ayarları → General → Reference ID. (xyz.supabase.co içindeki "xyz" kısmı)
O projede bu tablo yoksa SQL butonundaki "izlenen proje" script'ini orada çalıştır.

SQL script'leri

İki ayrı script var: biri bu panelin kendi verisini tutan proje için, diğeri izlediğin her proje için.

1) Bu panelin kendi Supabase projesinde bir kere çalıştır (uqdiiuqpkvqxunxthpbj)
create table if not exists public.tracked_apps ( id bigint generated by default as identity primary key, name text not null, project_id text not null, api_key text not null, table_name text not null default 'keepalive', last_updated timestamptz not null default now(), created_at timestamptz not null default now() ); alter table public.tracked_apps enable row level security; create policy "tracked_apps allow all" on public.tracked_apps for all using (true) with check (true);
2) İzlediğin her projede bir kere çalıştır (uyandırma tablosu)
create table if not exists public.keepalive ( id bigint generated by default as identity primary key, created_at timestamptz not null default now() ); alter table public.keepalive enable row level security; create policy "keepalive allow all" on public.keepalive for all using (true) with check (true);
